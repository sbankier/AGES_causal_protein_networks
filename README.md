## AGES causal protein networks

This repository is linked to the publication "Circulating causal protein networks linked to future risk of myocardial infarction" which can be accessed [here](https://www.nature.com/articles/s41467-025-67135-3). In this project, causal networks of human serum proteins were reconstructed using data from the Age, Gene/Environment Susceptibility-Reykjavik Study (AGES), a prospective population-based study of 7,523 serum proteins measured in 5,376 older adults. This repository contains code used for the reconstruction of these networks, data processing, and downstream analysis.
